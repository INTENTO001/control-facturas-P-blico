Conectar guardado entre dispositivos

Para que este registro se vea igual desde el celular, la laptop de la oficina, etc., conéctalo a un repositorio de GitHub. Los datos se guardan ahí, no en este navegador.

Este token se guarda solo en este navegador (nunca se sube al repositorio). Debes ingresarlo una vez en cada dispositivo desde el que quieras usar la herramienta.
